# dotfiles

Managed with [GNU Stow](https://www.gnu.org/software/stow/). Each top-level
directory is a "package" whose contents mirror paths under `$HOME`:

| Package | Stows | Notes |
|---------|-------|-------|
| `zsh/`  | `~/.zshrc` | sources `~/.pi/env` for MCP tokens |
| `tmux/` | `~/.tmux.conf` | |
| `vim/`  | `~/.vimrc` | |
| `dev/`  | `~/.gitconfig`, `~/.editorconfig` | |
| `config/` | `~/.config/*` (alacritty, kitty, nvim, sway, waybar, ...) | |
| `pi/`   | `~/.pi/agent/*` (settings, keybindings, models, mcp.json, extensions, themes) | secrets stay out, see below |
| `claude/` | `~/.claude/CLAUDE.md` | rest of `~/.claude` is machine-local |

Not stowed (see `.stow-local-ignore`):

- `dconf.ini` — apply with `dconf load / < dconf.ini`
- `tms.sh` — helper script

## Setup on a new machine

```sh
sudo dnf install -y stow   # or apt install stow
git clone <repo> ~/src/dotfiles
cd ~/src/dotfiles
./bootstrap.sh
```

`bootstrap.sh` pre-creates `~/.pi/agent` (so stow links *items* into it
instead of folding `~/.pi` into a symlink) and then stows all packages.

## Secrets (never committed)

- `~/.pi/agent/auth.json`, `mcp-auth.json` — generated by `pi` on login
- `~/.pi/env` — exports `GITHUB_MCP_TOKEN`, `OBSIDIAN_MCP_TOKEN`;
  referenced from `pi/.pi/agent/mcp.json` as `${ENV_VAR}`.
  Create it manually on a new machine:

  ```sh
  cat > ~/.pi/env <<'EOF'
  export GITHUB_MCP_TOKEN="..."
  export OBSIDIAN_MCP_TOKEN="..."
  EOF
  chmod 600 ~/.pi/env
  ```

- `~/.pi/agent/sessions/` — session logs, machine-local
